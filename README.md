# HR Analytics and Employee Attrition Prediction

## Project Overview

This project analyzes employee attrition and predicts whether an employee is likely to leave the organization using Machine Learning.

The application includes:

* Interactive HR Analytics Dashboard
* Employee Attrition Prediction System
* Data Visualization
* Business Insights
* Streamlit Web Application

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-Learn
* Streamlit
* Plotly

## Machine Learning Workflow

1. Data Cleaning
2. Exploratory Data Analysis (EDA)
3. Feature Engineering
4. One-Hot Encoding
5. Standard Scaling
6. SMOTE for Class Balancing
7. SVM (Support Vector Machine) Classification
8. Model Evaluation

## Dashboard Features

* Employee Count
* Attrition Rate
* Average Income
* Average Age
* Department Analysis
* Gender Analysis
* Attrition Distribution
* Top Job Roles with Highest Attrition

## Prediction Features

Users can enter employee details and receive:

* Attrition Prediction
* Probability Score

## How to Run

Install dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py

## Dataset

IBM HR Analytics Employee Attrition Dataset
